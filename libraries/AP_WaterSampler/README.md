# AP_WaterSampler — 水质采样杆驱动

采样杆由 **有刷直流电机 + 螺杆 + 限位开关** 组成，电机驱动器接受普通舵机 PWM 信号：

| PWM | 动作 |
| --- | --- |
| < 1500 | 杆**伸出** |
| > 1500 | 杆**收回** |
| = 1500 | **停止** |

到达限位开关时驱动器自己断电停转，飞控不需要限位开关反馈线。

驱动只做一件事：**收到一次"按下"信号 → 输出伸出 PWM → 计时 → 输出收回 PWM**。

## 一次采样的时序

```
收到按下信号 ──► 输出 WS_OPEN_PWM (1100) ──► 等待 WS_OPEN_TIME (10s) ──► 输出 WS_CLOSE_PWM (1900)
                    杆伸出（约5s到限位）        到位后继续压住5s             杆收回，然后停止驱动
```

合计 **10 秒**，其中约 5 秒行走、5 秒保持 —— 与 `WS_OPEN_TIME = 10` 一致。

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `WS_ENABLE` | `1` | 总开关。**置 0 后驱动完全不碰任何输出**（连触发通道都不读），是最安全的排查开关 |
| `WS_MOTOR_CHAN` | `9` | 驱动电机的舵机通道号，9 = `SERVO9`。对应 `SERVO9_FUNCTION` **必须为 0（Disabled）** |
| `WS_TRIG_CHAN` | `10` | 地面站用来"按按钮"的通道，10 = `SERVO10`。`SERVO10_FUNCTION` **必须为 0（Disabled）**，且该输出**不要接任何东西** |
| `WS_OPEN_PWM` | `1100` | 伸出 PWM，必须 < 1500 |
| `WS_CLOSE_PWM` | `1900` | 收回 PWM，必须 > 1500。杆收回后停在这个值，之后不再驱动 |
| `WS_OPEN_TIME` | `10.0` | 伸出持续时间（秒），范围 0.5 ~ 60 |

`WS_ENABLE` / `WS_MOTOR_CHAN` / `WS_TRIG_CHAN` 改动后**需要重启**。

## 接线

```
飞控 SERVO9 信号线 ──► 电机驱动器 PWM 输入
驱动器电源 ──► 独立电源（不要用飞控的舵机供电）
飞控 GND ──► 驱动器 GND （必须共地）
```

`SERVO10`（触发通道）**空着不接**，它只是地面站下命令用的"信箱"。

## 地面站（QGC）对接

核心只有一条 MAVLink 命令：

```
MAV_CMD_DO_SET_SERVO   (msgid = 183)
  param1 = 10      ← 触发通道号，填 WS_TRIG_CHAN
  param2 = 1900    ← 任意大于 1500 的值即可
```

驱动检测到触发通道出现 **上升沿**（从 ≤1500 变到 >1500）就启动一次采样。
连续按住不会重复触发，开机时如果通道已经是高电平也不会误触发。

⚠️ **所以每次采样前必须先"松手"**：一次采样结束后触发通道会停在 `1900`，
不先发一个 ≤1500 的值回去，第二次再发 `1900` 不构成上升沿，不会触发。

```
第一次采样：  直接发 (通道 10, 1900)
第二次以后：  先发 (通道 10, 1500) 松手，再发 (通道 10, 1900)
```

`SERVOx_FUNCTION` 不是 0（Disabled）的通道会被 ArduPilot 拒绝，并回报
`ServoRelayEvent: Channel N is already in use`，所以两个通道都必须设成 **0（Disabled）**。

### 上电后建议这样测

1. 先确认 `SERVO9_FUNCTION = 0`、`SERVO10_FUNCTION = 0`
2. 用手动方式给**通道 9** 发 `1100` → 这是"伸出"方向；发 `1900` 是"收回"方向；`1500` 停止
   （这一步同时验证了"AUX1 就是 SERVO9"）
3. 方向反了，就把 `WS_OPEN_PWM` 和 `WS_CLOSE_PWM` 对调
4. 再按上面的方法发 183 命令，走一遍完整的 10 秒时序

> 具体按钮入口随 QGC 版本而不同：凡是能发送自定义 MAVLink 命令的地方都可以用
> （QGC 的自定义动作、Mission Planner 的 Servo/Relay 页面、或任何 MAVLink 命令行工具）。
> 需要的只是那条 `DO_SET_SERVO`。

**没有收到任何命令时**：驱动**完全不碰电机输出** —— 上电、重启都不会让电机转动，只有收到命令才会动。

## 与水质传感器的关系

两者互相独立：

- 水质传感器用 `WQ_SERIAL` / `SERIALx_PROTOCOL = 51`，走串口；
- 采样杆只用舵机输出，不碰串口。

采样杆**不会**自动触发水质测量；如果需要"伸出 → 稳定 → 测量 → 收回"，请在地面站侧按时间编排。

## 编译时开关

`libraries/AP_WaterSampler/AP_WaterSampler_config.h` 中：

```c
#define AP_WATERSAMPLER_ENABLED 1   // 置 0 可完全不编译此驱动
```

## 故障排查

| 现象 | 检查 |
| --- | --- |
| 按按钮没反应 | `WS_ENABLE`=1？`SERVO10_FUNCTION`=0？地面站确实发出了 183 命令（看 MAVLink 消息）？ |
| 电机不动 | `WS_MOTOR_CHAN` 是否正确？`SERVO9_FUNCTION`=0？`SERVO9` 是否对应你的 AUX OUT 1 排针？ |
| 方向反了 | 对调 `WS_OPEN_PWM` 和 `WS_CLOSE_PWM` |
| 杆伸得到位但收回不及时 | 增大 `WS_OPEN_TIME`（总时长 = 行走 + 保持） |
| 怀疑采样杆导致异常 | **把 `WS_ENABLE` 设为 0 重启**，驱动即完全静默，可用来判断问题是否出在采样杆 |
